# Hello World Outlook Add-in

Minimal Outlook add-in (XML manifest + static task pane) hosted on GitHub Pages.

- Task pane: https://dfvdfvdfvdfdsdju63434f.github.io/hello-world-outlook-addin/taskpane.html
- Manifest: https://dfvdfvdfvdfdsdju63434f.github.io/hello-world-outlook-addin/manifest.xml

## Install (Outlook on the web)
1. Open an email in https://outlook.office.com/mail
2. Open the add-ins dialog (`...` > Get Add-ins) or go to https://aka.ms/olksideload
3. My add-ins > Custom add-ins > Add a custom add-in > Add from URL
4. Paste the manifest URL above.

Requires an Exchange-backed mailbox (Microsoft 365 / Outlook.com). IMAP accounts (e.g. Gmail added to Outlook) cannot host add-ins.
